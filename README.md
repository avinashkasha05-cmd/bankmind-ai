# BANKMIND AI

An independent educational prototype for banking intelligence and relationship management.

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Current features
- Overview dashboard
- Relationship Coach with fictional customer profiles
- Credit Intelligence with illustrative financial ratios
- About and safeguards

## Important safeguards
- Uses fictional demonstration data only.
- Not affiliated with or endorsed by ICICI Bank, JPMorgan Chase, or any other financial institution.
- Not for credit decisions, investment advice, compliance determinations, or production banking use.
- Human validation is required.
